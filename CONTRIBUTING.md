# Contributing / Operating Rules

This repository template is designed for controlled AI-assisted development.

## Human approval

No agent should execute code-changing tasks unless a human reviewer has approved the task.

## Safe changes

Documentation-only workflow changes may be added after review. Code changes should be isolated in branches and reviewed before merge.

## Historical records

Do not rewrite old reports, accepted ADRs, or decision logs unless there is an explicit correction note.

## Private data

Never add raw private data, credentials, tokens, cookies, or production dumps to the repository.
